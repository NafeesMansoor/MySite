        How to use StateTrace

        Build the machine

        • Double-click the boardAdd a state, then type its name
        • Shift + drag between two statesAdd a transition, then type its symbols
        • Shift + drag inside one stateAdd a self-loop
        • Shift + drag from the empty board onto a stateMark the start state
        • Double-click a stateToggle accepting (double circle)
        • Drag a state or a transitionMove it, or bend the arrow
        • Click, then type or use the Label boxRename a state or relabel a transition
        • Delete (Fn + Delete on a Mac)Remove the selection
        • Ctrl/Cmd + Z, add Shift to redoUndo or redo an edit

        The toolbar on the board does the same without a keyboard, which is how to build a machine on a touch screen.

        Label transitions

        • aRead the symbol a
        • a, bRead a or b (one character per symbol)
        • \epsilon or \lambdaMove without reading a symbol (ε-move)
        • q_0, \alphaSubscripts and Greek letters in names

        Trace an input

        • Type an input string, press ExecuteRun the machine; leave it empty to test the empty string
        • Play, Pause, Next, Previous, ResetMove through the run one symbol at a time
        • Click a row of the execution traceJump to that step

        The machine is a DFA when every state has at most one move per symbol and there are no ε-moves; otherwise it runs as an NFA and every state it could be in is highlighted at once.

        Move around

        • Drag the empty boardPan
        • Pinch, or Ctrl/Cmd + scrollZoom
